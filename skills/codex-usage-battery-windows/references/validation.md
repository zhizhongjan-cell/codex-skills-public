# 验证标准与记录

来源版本：1.0.0。本文下列46项回归与独立Agent演练描述的是原版本实测；1.0.1仅修改许可分发、元数据及运行目录清单，功能源码未变。验证日期：2026-10-20。

## 来源与已知边界

源流程多次执行过应用事件激活、现有窗口再激活、跨进程同启同退及冷启动回归。曾有两类真实故障：窗口尚未就绪被30秒期限提前终止，以及托管可见但层级被盖住。两者修复均在源码和回归中保留；不把这段历史推导为所有 Windows/Codex版本均可用。

制作包时仅复制 allowlist 的9份源码/构建/测试文件，移除旧启动 Codex 分支；增加可选 CLI 配置、只读检查、构建、预览/登记、停用和测试脚本。无用户名、SID、账户额度快照、历史日志、任务XML、编译exe或快捷方式。新机必须本地探测。

## 生产验收矩阵

逐项记录“已验/未验/失败”、时间和证据，不能默认全部已验：

1. 当前前台 Codex 顶部有电池，真实额度对得上；截图/人工可见证据和 nativeVisible/uncoveredAtCenter 互证。
2. 移动/缩放窗口跟随；最小化/切走隐藏；恢复/切回显示；不抢焦点。
3. 关闭最后窗口后约1秒退出；新开窗口再次触发；多个启动入口实际产生已订阅事件。
4. 登录后不开 Codex，无电池等待进程、无工具新启的 Codex进程。
5. 下一次真实 Windows 重启登录，再正常打开Codex，电池出现；关闭后退出。

本次制作包不登记/迁移生产任务，不关闭用户Codex，也不重启Windows。第4、5项真实开机验收未执行；跨机器、其他打包方式未验。模拟冷启动只验证延迟容错，不能冒充实际开机结果。

本次隔离构建已通过46项功能回归，Windows PowerShell 5.1 完整入口也已重跑通过；冷启动报告实际用时33.7秒。额外14项脚本边界检查通过，覆盖默认只预览、目录不覆盖、路径/AppID拒绝、任务冲突、子文件夹同名任务和预览身份设置。只读真实用量 probe 成功，未将额度数值带入本包。

未参与设计的独立Agent已按包内说明完成PS5.1环境检查、Prepare预览、State检查；确认预览不建目录，已有旧电池任务会阻止新部署。它发现的根目录扫描限制及预览信息不足已修正并复核。没有为这些测试登记或停用真实任务。

源包结构、脚本语法、CRC、机器资料排除和交付副本SHA-256检查另由外部交付验证报告记录。报告必须写本次实际结果，不能把下一次开机或跨机器验证列为通过。
